# PDF 정리기

광고 없는 PDF 페이지 편집기. 브라우저 안에서만 동작하며 파일은 외부로 전송되지 않습니다(구글 드라이브 연동 시 드라이브와만 주고받음).

- 탭으로 여러 PDF 열기, 탭 사이 쪽 복사·붙여넣기(Ctrl+C / Ctrl+V)
- 쪽 삭제·회전·드래그 이동·빈 쪽·병합·추출
- 글자 덮어쓰기(가리고 새로 쓰기)
- Ctrl+S로 원본 파일(또는 드라이브 원본)에 덮어쓰기
- 설치형 앱: PDF 연결 프로그램으로 등록, 오프라인 실행

주소: https://dleogks2-dot.github.io/GOMIDA/pdf/
